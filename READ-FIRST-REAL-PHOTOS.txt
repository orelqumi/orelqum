HOW TO DEPLOY
1. Extract all ZIP contents.
2. Open extracted Orelqumi_Real_Photo_Cards_Cache_Fix folder.
3. In File Explorer's address bar, type cmd and press Enter.
4. Run: wrangler pages deploy public --project-name orelqum --branch main
5. Wait until Deployment complete.
6. FIRST open the new deployment preview URL printed by Wrangler.
7. THEN open https://orelqum.pages.dev/?release=photo-v3-20261113 . Both should show the same image cards after production branch deployment.
8. If one tab still shows an older page, close ALL tabs for the site and open a new InPrivate/Incognito window; clear browser site data if needed. Note Pages preview URLs are frozen to the version originally deployed. Never compare a past preview URL to the main site's latest version.
