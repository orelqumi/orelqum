DEPLOYMENT
1) Extract this ZIP. Upload extracted files and folders (public, functions, db, wrangler.json, and docs) to GitHub repo root if desired.
2) Your Cloudflare Pages project uses Wrangler direct deployment: GitHub uploads alone do not automatically publish this site.
3) In the extracted folder, open Windows Command Prompt and run:
   wrangler pages deploy public --project-name orelqum --branch main
   Check the Cloudflare binding DB -> orelqumi-portal and PAYSTACK_SECRET_KEY (encrypted) before using private features.
4) Check https://orelqum.pages.dev/ on actual Android and desktop browsers.
